# Strata

The application lives here. See the [main README](../README.md) at the repository root for
features, screenshots, architecture and setup instructions.

## Quick start

```bash
npm install
npx convex dev     # in one terminal
npm run dev        # in another, then open http://localhost:3000
```

Requires a `.env` in this directory. The variables are listed in the
[main README](../README.md#environment-variables).
